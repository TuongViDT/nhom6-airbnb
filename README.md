# CybersoftBnb Website – Test Automation Project

## 1. Project Overview
This project focuses on testing a Hotel Booking Website, including both manual testing and automation testing, to ensure system quality and reliability.

## 2. Scope of Testing
- Authentication (Register, Login, Logout)
- Search rooms by location, date, and number of guests
- Room booking
- User profile management

## 3. Test Types
- Manual Testing
- Automation Testing

## 4. Tools & Technologies
- Test case management: Google Sheets
- Bug tracking: Jira
- Automation framework: Playwright
- Programming language: Java

## 5. Test Automation
- Automated critical test scenarios
- Page Object Model (POM)
- Test execution on Chrome browser
- Test report generation

## 6. How to Run Tests
npm install  
npx playwright test

## 7. Test Environment
- URL: https://demo5.cybersoft.edu.vn/
- Browser: Chrome
